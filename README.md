Entry for the make.fun bounty "The Comment Above the Code": one funny,
painfully honest line imagining the comment a developer left above fragile
production code — the kind of line that is funny because it is true.

## Run it

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`).
